## 职责与输入输出

输入为通过阶段 D/E 门槛的候选版本、真实冻结报告和运行指南；输出为三分钟视频、PPT、README、环境变量/离线降级说明、源代码和提交压缩包。展示不得发明产品能力或效果数字。

## 物料约束

Demo 按 S00015 → S00024 → S00001 展示证据、待核实、普通售后和人工确认；评测收束只在冻结集真实报告存在后展示。现场无网无密钥必须走 Mock；Qwen 切换需显示 Provider 和降级原因。扩展图片必须标注合成数据。初赛 PPT/视频和决赛 PPT/可运行 Demo/源码运行指南的官方交付要求以 `赛题要求.txt` 为材料来源。

## 工程选型与运行说明迁移

目标交付工程采用 React + Vite / FastAPI；建议目录为 `backend/`、`frontend/`、`data/`、`eval/`、`docs/`，并提供 `README.md`、`.env.example`、`requirements.txt`。这是旧 SPEC 的工程约定和后续交付目标，不是当前实现事实。README 至少说明本地启动、Excel/数据放置、Qwen 配置、Mock/Rule 降级、Provider 状态、评测命令和已知限制。
