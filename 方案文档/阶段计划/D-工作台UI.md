# 阶段 D：工作台 UI

- 版本：v0.3
- 日期：2026-09-13

进入条件：真实 Agent/Provider 主路径可返回统一 JSON；保留现有静态交互基线。涉及 UI-T001–T004，可在 UI-T001 接通后并行做详情和状态。

实施范围以 [工作台 SPEC](../模块规格/04-客服工作台与证据交互-SPEC.md#interaction) 和 [工作台任务](../模块任务/04-客服工作台与证据交互-TASKS.md) 为准：UI-T001 承接消息回放、三个快照入口及搜索边界；UI-T002 承接证据、工具详情与草稿，必须沿用同一 `analysis_id` 和 Agent 运行记录，人工升级仅生成本地草稿；UI-T003 承接判断卡内紧凑状态入口、人工确认、过期校验和按需日志，只有 `safety_check_result.status=pass` 且版本/草稿校验通过才可确认；UI-T004 复核交互完整性、窄屏/键盘与效率原则。

产物为可运行工作台及 [UI-C001–UI-C004](../模块验收/04-客服工作台与证据交互-CHECKLIST.md) 对应的路径录屏、截图、快照/运行/处置记录。工具详情、日志和校验明细不另增首屏面板；不能因按需展开而漏实现。

退出条件：[UI-C001–UI-C004](../模块验收/04-客服工作台与证据交互-CHECKLIST.md) 全部通过；三主案例、证据、草稿、人工确认和状态跟踪可操作。当前 HTML 状态选择器缺确认与日志、部分快捷入口缺禁用状态，不作为通过证据；静态回归与真实接入分别留证。当前：待 C。
