## 证据层级约定

- 阶段 A/B 的报告只能作为输入契约和规则/契约前置证据，不能替代本表的 Agent 运行证据。
- 固定 Mock 输出、静态 UI 节点、预设工具结果和固定耗时只能证明展示或离线链路，不证明模型效果或业务收益。
- 每项状态只有在对应运行记录和可核对证据存在后才能改为“通过”。
